สรุปมาตรฐานวิชาการจากไฟล์ Retopoforanimat.md

คำจำกัดความและเป้าหมายของ Retopology

Retopology คือกระบวนการปรับโครงสร้าง Polygon/Topology ของโมเดล 3 มิติใหม่ โดยมีเป้าหมายเพื่อให้โมเดลมีจำนวน Polygon ที่เหมาะสม มีการไหลของ Edge ที่เหมาะกับการ Rigging, Skinning, Animation, UV Mapping และการทำ Texture

1. หลักการสำคัญ 4 ด้าน (Core Principles)

  • Edge Flow: ทิศทางของ Edge ต้องไหลไปตามแนวมัดกล้ามเนื้อ แนวกราม รอบดวงตา และรอบปาก เพื่อรองรับการแสดงสีหน้าและการพับตัว
  • Edge Loop: วงเส้นต่อเนื่องแบบลูปปิดเพื่อควบคุมการเสียรูปของ Mesh บริเวณข้อต่อ
  • Pole Management: หลีกเลี่ยงจุดเชื่อม 3 หรือ 5 เส้น (Poles) บริเวณที่มีการยืดพับสูง เพื่อป้องกันรอยร่น Pinching
  • Quad Topology: รักษาสัดส่วนเฟส 4 ด้าน (Quad) ให้อยู่ระดับ 95-100% เพื่อรองรับ Subdivision และ Skinning

2. มาตรฐานสำหรับ Character Animation

  • Facial Loops: ลูปวงกลมซ้อนรอบดวงตา (กะพริบ/หรี่) และลูปรอบริมฝีปาก (พูด/ยิ้ม) สัมพันธ์กับ Facial Rig
  • Joint Bending: เพิ่ม Edge Loop 3 วงบริเวณข้อศอก เข่า และข้อนิ้ว ป้องกันโพลีกอนแบนยุบลงเมื่อพับขาสุด
  • Dynamic Density: พื้นที่เคลื่อนไหวสูง = เพิ่มความหนาแน่น; พื้นที่นิ่ง = ลดจำนวนโพลีกอนลง

3. Pre-Rigging Checklist (10 ข้อตรวจสอบความพร้อม)

  1. รูปทรงโมเดลตรงตาม High-poly ต้นฉบับ
  2. ไม่มี Vertex หรือ Face ซ้อนกันโดยไม่จำเป็น
  3. Normals หันออกด้านนอก 100%
  4. Edge Flow ไหลตามแนวมัดกล้ามเนื้อ
  5. บริเวณข้อต่อมี Edge Loop เพียงพอ
  6. ใบหน้ามี Loop รองรับ Facial Animation
  7. จำนวน Polygon เหมาะสมกับงาน
  8. ทดลอง Deformation เบื้องต้นแล้ว
  9. พร้อมสำหรับการทำ UV Unwrapping และ Seam
  10. ตั้งชื่อ Object เป็นระบบก่อนส่งต่อให้ Rigging
